Parsa Tak WEB — v2.0.0 upgrade package (2026-09-10)
================================================

WHAT THIS IS
The complete final repository state after the performance,
data-pipeline, and blog upgrade. Copy the WEB-UPGRADE/ folder
contents over your repository root (or replace the repository
contents with them), then commit and push. Paths are
repo-relative.

HIGHLIGHTS
  - Scene chunk deduplication: every scene has exactly one
    dynamic import site (ScenePreloader). Deployed JS drops
    from 27 chunks / ~968 KB to ~20 chunks / ~753 KB, and each
    scene navigation downloads its chunk once instead of twice.
  - Loading architecture: five honest load phases (no fake
    percentages), P0–P4 priority ladder, idle-gated background
    preloading that skips hidden tabs and save-data/2G, and a
    scene overlay that never flashes for preloaded transitions.
  - Data layer: lib/resourceStore.ts (request deduplication,
    failure cleanup, abort awareness), runtime validation in
    lib/contentRepository.ts, typed blog access in lib/blog.ts.
  - BLOG: /blog/ index (featured article, search + tag filter),
    /blog/<slug>/ article pages (SEO, Open Graph, JSON-LD,
    prev/next, related posts), RSS at /blog/feed.xml — all
    statically exported from content/blog/*.md through
    scripts/build-blog.mjs (zero dependencies).
  - Toolchain repaired: npm run lint now actually passes
    (eslint realigned to 9.x; the previous eslint@10 stack
    crashed on every run — CI never ran lint, so it was silent).
  - not-found redirect fixed to stay inside /WEB.

HOW TO APPLY
  1. Copy the WEB-UPGRADE/ contents over your repository root
     (allow overwrites). All files are complete replacements —
     no patches to merge.
  2. Install dependencies (devDependencies changed: eslint
     realigned): npm ci --legacy-peer-deps
  3. Commit: git add -A && git commit -m "v2.0.0: loading
     architecture, data pipeline, deduplication, and blog"
  4. Push: git push origin main
  5. Watch the newest GitHub Actions run (must be green), then
     hard-refresh https://parsaetak.github.io/WEB/

VERIFY AFTER PUSH (90 seconds)
  - Home: organism animates; all six scenes open; hover a scene
    button then click it — the transition shows no full-screen
    loader flash when the chunk was preloaded
  - HUD: "Blog ↗" button opens /WEB/blog/
  - Blog: featured card, search box (try "constraints"), tag
    chips (try "performance" -> 2 cards), article links,
    prev/next navigation, related posts, "Back to the world"
  - Blog header scene links (e.g. MAGIC) return to /WEB/#magic
  - /WEB/blog/invalid-slug/ redirects to /WEB/blog/
  - /WEB/blog/feed.xml serves valid RSS
  - Phone width (~390px): blog index and articles show no
    horizontal overflow; article text stays readable
  - No console errors

NOTES
  - npm ci is REQUIRED once (package-lock.json changed with the
    eslint realignment). No runtime dependencies were added:
    the markdown pipeline, RSS generation, data layer, and
    search are all custom, zero-dependency code.
  - data/blog/posts.json and public/blog/feed.xml are
    GENERATED by scripts/build-blog.mjs on every build. They
    are committed so a fresh clone works immediately; never
    hand-edit them.
  - Adding an article: drop a markdown file into content/blog/
    and run npm run build (or npm run blog). The build fails
    loudly if the frontmatter is malformed.
  - Do NOT hand-edit data/library.json (synced at build time).

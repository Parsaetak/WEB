Parsa Tak WEB — v2.4.0 full regression + UI cleanup + SEO hardening
(2026-09-11)
=================================================================

WHAT THIS IS
The complete final repository state after the v2.4 quality pass.
Replace the repository contents with these files (or copy them over
your repository root), then commit and push. Paths are repo-relative.

HIGHLIGHTS
  - Interaction truth: every control that promises an action now
    performs it. The Home "systems overview" block and the three
    system rows are real links (overview and REP/USEF open the
    Systems scene; AI INSTRUCTIONS opens its article). The Systems
    AI-INSTRUCTIONS module card is one full-card link to its
    article. The Work RED MAGIC project card opens the Magic scene.
    Inert cards (About principles, Home direction stages, REP/USEF
    modules, non-linked Work projects) no longer carry hover-lift
    affordances — nothing looks clickable unless it is.
  - Truthful status text: the loading ERROR phase now says
    "RELOAD TO RETRY" (a reload is the actual recovery path)
    instead of promising a retry control that never existed.
  - Text style rule: short UI text and display headings no longer
    end with a terminal period ("Research / Build / Repeat",
    "What I am building", "The works / Read, watch / listen",
    "Run the experiment", "Writing from the laboratory", and the
    PDF reader fallback). Full prose keeps normal punctuation.
  - Link correctness: both "MAGIC laboratory" links inside blog
    articles now open the Magic scene (/#magic) instead of
    unrelated articles; a natural related-article link was added
    to keep the living-system article connected.
  - SEO hardening (no spam): SHEYTAN appears once in site
    keywords and once in the Person entity description; "Red
    illuminati" appears once in site keywords and as one visible
    tag on the RED MAGIC article. No hidden text, no keyword
    walls, no manufactured entities — every term names something
    the site actually presents.
  - Honest dates: only the two articles genuinely edited in this
    release carry updated 2026-09-11; all other article dates and
    the publication history are untouched.
  - New automated checks: npm run verify:seo now audits the
    exported HTML for dead interactions (href="#", empty href,
    javascript: URLs, unresolvable internal links — basePath
    aware) and label punctuation (no uppercase label-style text
    ending in "."). CI runs it on every deploy.
  - Dead code removed: SceneErrorState component and .sceneError
    CSS (never rendered anywhere).

HOW TO APPLY
  1. Replace your repository contents with these files (allow
     overwrites). All files are complete replacements — no
     patches to merge.
  2. Install dependencies: npm ci (dependencies unchanged from
     2.3; no new dependencies at all).
  3. Commit: git add -A && git commit -m "v2.4.0: full regression
     audit — interaction truth, text style rule, link fixes, SEO
     hardening"
  4. Push: git push origin main
  5. Watch the newest GitHub Actions run (must be green — it
     includes the extended SEO verification step), then hard-refresh
     https://parsaetak.github.io/WEB/

HOW TO APPLY
  1. Replace your repository contents with these files (allow
     overwrites). All files are complete replacements — no
     patches to merge.
  2. Install dependencies: npm ci (dependencies unchanged; no new
     runtime dependencies at all).
  3. Commit: git add -A && git commit -m "v2.6.1: mobile
     navigation, blog header navigation fix, project-connected
     articles"
  4. Push: git push origin main
  5. Watch the newest GitHub Actions run (must be green — it runs
     the blog pipeline and the extended SEO verification), then
     hard-refresh the live site.
